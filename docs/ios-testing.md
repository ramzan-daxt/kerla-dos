# Тестирование Kerla Doş на iPad через Xcode

Оболочка Capacitor 8.5.1, как в Lamaz Xan. Отдельный Bundle Identifier:
`com.kerlados.app`. Встроена статическая сборка Next.js из `out/`:
локальный сервер и постоянно включённый Mac не нужны. Данные Safari/PWA
не переносятся автоматически; приложение хранит свой прогресс отдельно.

## Обновить и открыть

Из корня `kerla-dos`:

```sh
npm run ios:sync
npm run ios:open
```

`ios:sync` сначала собирает актуальный сайт и только затем копирует его в
нативный проект. Не редактируйте `ios/App/App/public` вручную.

## Установить на свой планшет

1. Подключить и разблокировать iPad, подтвердить доверие Mac.
2. Открыть `ios/App/App.xcodeproj`, выбрать схему `App` и свой `iPad`.
3. Target **App → Signing & Capabilities**: включить **Automatically manage
   signing**, выбрать свою **Personal Team** (как в Lamaz Xan).
4. Нажать **Run ▶**. Если iPad попросит, включить Developer Mode и подтвердить
   доверие приложению разработчика в настройках устройства.

Не менять Bundle Identifier после начала тестирования и не удалять приложение
без необходимости, чтобы не потерять локальный прогресс. При истечении
тестовой подписи повторить запуск через Xcode.

## Проверки на реальном iPad

- Портретная и горизонтальная ориентация; края экрана и системные панели.
- Карточки: аудио, остановка при перелистывании, сердечко и избранное.
- «Ловза», «Дош гулде», мозаика и перелистывание книг.
- Перезапуск: сохранение прогресса и избранного.
- Запуск без интернета: доступность встроенных иллюстраций и записей.

Проверка компиляции не заменяет эти проверки на устройстве. Вибрация через
браузерный API не гарантируется в iOS; нативные плагины вибрации в этой задаче
не добавлялись. Публикация в App Store/TestFlight не настроена и не выполнялась.

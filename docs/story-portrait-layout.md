# Story portrait layout

Local work, 2026-09-06. The user approved portrait adaptations of all eleven scenes.

Originals: `public/stories/borz-ka/scene-01.png` through `scene-11.png`, preserved unchanged.
Outputs: corresponding `scene-01-portrait.webp` through `scene-11-portrait.webp`, 887 × 1774 pixels.

Image-generation direction: use each original as the reference; preserve its characters, action, count and illustrated style; produce a full-bleed 1:2 portrait composition with an unobtrusive sky or meadow area opposite the characters. No lettering or brush baked into the picture. Generated PNGs were encoded to WebP at quality 88.

One shared HTML text wash per page. Its position is individually assigned:

| Scene | Wash |
| --- | --- |
| 1 | Top |
| 2 | Top |
| 3 | Bottom |
| 4 | Bottom |
| 5 | Top |
| 6 | Bottom |
| 7 | Top |
| 8 | Bottom |
| 9 | Top |
| 10 | Bottom |
| 11 | Top |

Scene 8 removes spare sky with a vertical image offset to accommodate its longer text. Dialogue uses paired guillemets; attribution stays outside them. Independent narration remains a separate paragraph. Audio source blocks are not rewritten.

All eleven pages were inspected in browser layouts at 320, 414, 768 × 1024, 1024 × 768 and 1180 × 820. These are browser viewport checks, not physical-device certification. Portrait art is also used in a centered, height-constrained page on tablets. Original landscape artwork remains available for a future separately designed landscape composition.

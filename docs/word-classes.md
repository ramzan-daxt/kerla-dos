# Классовые плашки: проверка текущих карточек

Источник: А. Г. Мациев, Чеченско-русский словарь (1961), [электронный PDF](https://ps95.ru/wp-content/uploads/2018/07/Maciev_A.G_Chechensko-russkiy_slovar.pdf). Номера PDF-страниц для каждой подтверждённой формы записаны в `app/word-classes.ts` (classEvidence).

Показатели в/й/д/б отображаются как ву/йу/ду/бу. Это классы, не русские роды. Неподтверждённые слова не получают предположительный цвет. Переводы и аудио не менялись.

Особые соответствия: йетт — словарное етт; мар — отсылка к майра¹; гай — ге; мӀара — маӀар² (ноготь, не рог). Множественные формы: дай (да), месаш (мас), кемсаш (кемс), пазаташ (пазат), каранаш (кара), эткаш (этка), басарш (басар). Использован показатель множественного числа. Для омонимов выбраны значения карточек: гӀала — башня, балл — вишня, ша — лёд, марха — облако, сту — бык, бага — рот.

Требуют уточнения: двойной класс в/й у шича, хьехархо, дешархо, йаздархо; составные названия родственников; формы, не сопоставленные однозначно со словарной статьёй. «Без плашки» для чисел, цветов и наречий — намеренное отсутствие фиксированного именного класса, а не пропуск.
